# Portfolio - Mouadh FERSI

Portfolio personnel moderne et professionnel créé pour présenter mes compétences, expériences et projets dans le domaine du développement web full-stack.

## 🎯 Objectif

Ce portfolio a été conçu pour m'aider à trouver un **stage de fin d'études (PFE)** en développement web full-stack.

## ✨ Fonctionnalités

- **Design Moderne** : Interface élégante avec thème sombre et animations fluides
- **Thème Clair/Sombre** : Basculez entre les modes avec sauvegarde de préférence
- **Responsive** : Parfaitement adapté à tous les écrans (mobile, tablette, desktop)
- **Animations** : Effets d'animation au scroll et transitions élégantes
- **Navigation fluide** : Smooth scroll entre les sections
- **Performance optimisée** : Chargement rapide et optimisé

## 🚀 Installation et Utilisation

### Option 1: Ouverture directe
1. Ouvrez le fichier `index.html` dans votre navigateur

### Option 2: Serveur local
```bash
# Avec Python 3
python -m http.server 8000

# Avec Node.js (npx)
npx serve

# Avec PHP
php -S localhost:8000
```

Puis ouvrez `http://localhost:8000` dans votre navigateur.

## 📝 Personnalisation

### Remplacer la photo de profil

1. Ajoutez votre photo dans le dossier `assets/`
2. Dans `index.html`, remplacez la section placeholder :

```html
<!-- Remplacer -->
<div class="profile-placeholder">
    <i class="fas fa-user"></i>
</div>

<!-- Par -->
<img src="assets/votre-photo.jpg" alt="Mouadh FERSI" style="width: 100%; height: 100%; object-fit: cover; border-radius: 50%;">
```

### Modifier les couleurs

Dans `css/style.css`, modifiez les variables CSS au début du fichier :

```css
:root {
    --primary-color: #7c3aed;     /* Couleur principale */
    --secondary-color: #06b6d4;   /* Couleur secondaire */
    --accent-color: #f59e0b;      /* Couleur d'accent */
}
```

### Ajouter/Modifier le contenu

Éditez directement le fichier `index.html` pour modifier :
- Vos informations personnelles
- Vos expériences
- Vos projets
- Vos compétences
- Vos certifications
